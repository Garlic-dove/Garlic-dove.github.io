MySQL

是什么

MySQL是靶场内部的一个服务组件。

  • 在靶场练习SQL注入时，攻击的最终目标就是操纵后端代码对MySQL数据库发出的查询语句。
  • 注入的Payload（恶意代码），最终是在MySQL这个数据库系统中被执行的。我们利用的是应用程序层的漏洞，去影响数据库层。

    学习和MySQL数据库对话，了解如何运用MySQL的语法。

查询语句

  • union 合并

    如果前面的列数（user）比后面的列数（emails）少，则不能用*查询，需要查询具体的列名
    如果前面的列数（user）比后面的列数（emails）多，可以添加填充列

  • group by 分组

    如果有一列的内容相同，但是处于不同的id行，分组一列没有问题，但是对多列分组将会报错

  • order by 默认按照升序排列

    通过查看是否有列数可以进行排列判断列数（当没有列可以排列将报错）

  • limit 限制输出内容数量

    limit一般用于限制显示报错反馈信息，在这里从零开始记为第一行

  • and 和 or “与”和：“或”

  • group_concat 合并到一行显示

  • select database() 查看当前数据库名称

  • select version() 查看当前数据库版本

SQL注入

什么是SQL注入

SQL注入，就是通过把SQL命令插入到web表单提交或输入域名或页面请求的查询字符串，最终到达欺骗服务器执行恶意的SQL命令，从而进一步得到相应的数据信息。

通过构造一条精巧的语句，来查询到想要得到的信息

  • 查询字段
    • 字符型：输入的参数为字符串
    • 数字型：输入的参数为整形
  • 注入方法
    • Union注入
    • 报错注入
    • 布尔注入
    • 时间注入

判断字符型还是数字型注入

注入点是可以实行注入的地方，通常是一个访问数据库的链接点，在注入点输入指令对网页的显示进行判断。
使用and 1=1和and 1=2来判断（and 3-1）

可以在sqli-labs进行测试
Less-1提交and 1=1和提交and 1=2都能正常显示面，则为字符型注入

Less-2提交and 1=2条件无法满足，语句无法被数据库查询到，网页无法显示，判断为数字型注入

打开源文件，查看源代码可以看见指令

/var/www/html/sqlilabs/Less=1/Index/php
字符型需要闭合符

1 and 1=1被视为字符，不会被当作指令执行

数字型不需要闭合符来闭合

1=2不满足条件，不会执行查询指令

判断闭合方式

闭合方式
'、"、')、")等

Less-1输入?id=1'，报错信息''1'' LIMIT 0,1'多一个'，判断闭合符号为'

less-3输入id=1'，报错信息''1'') LIMIT 0,1'多一个')，判断闭合符号为')

闭合的作用
手工提交闭合符号，结束前一段查询语句，后面就可以加入其他语句，多出的闭合符号或不需要的语句可以用注释符号--+、#或%23注释掉

union联合注入

提交’?id=1’ union select database() --+
可能报错：columns（列）数量错误，需要判断页面数据列数量

假设列数为3，为id、username、password。

提交?id=1’ union select 1,2,3 --+

页面只能显示一个内容，第二句的内容是不显示的（id内容一般也不显示），但是可以修改id为不存在的数据（id=-1），这样就只会显示第二个指令的内容

提交?id=-1’ union select 1,2,3 --+

提交?id=-1’ union select 1,version(),database() --+

  3. 如果是字符型，找到闭合方式
  4. 判断查询列数group by、order by
